Endpoint matrix

Throughput, tail latency, and the server process's own CPU and memory per endpoint, every runtime on the same handler code. CPU per request is user + system time of the server divided by requests served, read from its /stats endpoint at the edges of the measured window. Bars are sorted; color is the I/O model family, the name is the runtime, ◆ marks the runtimes built in this repository.

Connection sweep

Throughput as keep-alive connections grow (one request in flight per connection), server pinned to 2 cores. Shared y scale; one panel per runtime because eleven converging lines on one plot cannot be read.

Worker sweep

Throughput by worker count at 1024 connections on a 2-core server. One worker is the 1-vCPU droplet case; four workers on two cores is oversubscription.

Expanded load shapes

Five shapes the endpoint matrix does not cover. Same handler code, same 2-core pinning as the sweeps.

HTTP/1.1 pipelining

16 requests per write on 64 connections. The parser answers a whole batch in one pass; the runtime decides how many syscalls or ring operations that costs.

10 000 stalled connections

Each idle socket sent half a request line and then went silent (slowloris) while 64 hot connections were measured. A runtime that holds a thread per connection runs out of threads; a pool runs out of pool.

Mixed paths

Every connection rotates /json, /compute?n=2000 and / so one request stream carries a small response, a CPU-bound one and a trivial one.

Noisy co-tenant

A busy loop pinned to one of the server's two cores for the whole run: a cron job, a log shipper, or a neighbour on a shared vCPU. Shows who degrades gracefully.

Long-window tails

20 s at 256 connections so p99.9 and p99.99 rest on tens of thousands of samples, not a few.

Open-loop rate sweep

p99 latency measured from the intended send time while the client offers a fixed request rate over 256 connections. Where a line turns upward the server has stopped keeping up and queueing delay takes over: that is the runtime's knee on a 2-core server. Values are clipped at 50 ms.
