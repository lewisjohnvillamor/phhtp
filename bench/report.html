Endpoint matrix

Throughput, tail latency, and the server process's own CPU and memory per endpoint, every runtime on the same handler code. CPU per request is user + system time of the server divided by requests served, read from its /stats endpoint at the edges of the measured window. Bars are sorted; color is the I/O model family, the name is the runtime, ◆ marks the runtimes built in this repository.

Connection sweep

Throughput as keep-alive connections grow (one request in flight per connection), server pinned to 2 cores. Shared y scale; one panel per runtime because eleven converging lines on one plot cannot be read.

Worker sweep

Throughput by worker count at 1024 connections on a 2-core server. One worker is the 1-vCPU droplet case; four workers on two cores is oversubscription.
